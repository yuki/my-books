|:-----|:-------------|

[<br>]{.verbatim}         |	Defines a single line break |
[<button>]{.verbatim}     |	Defines a clickable button |

**NO soportadas** en HTML5:

| Tag | Descripción |
|:-----|:-------------|
| [<acronym>]{.verbatim}	| **Not supported in HTML5.** Use [<abbr>]{.verbatim} instead. Defines an acronym |
| [<applet>]{.verbatim}	    | **Not supported in HTML5.** Use [<embed>]{.verbatim} or [<object>]{.verbatim} instead. Defines an embedded applet |
| [<basefont>]{.verbatim}	| **Not supported in HTML5.** Use CSS instead. Specifies a default color, size, and font for all text in a document |
| [<big>]{.verbatim}	    | **Not supported in HTML5.** Use CSS instead. Defines big text |
| [<center>]{.verbatim}	    | **Not supported in HTML5.** Use CSS instead. Defines centered text |
| [<dir>]{.verbatim}	    | **Not supported in HTML5.** Use [<ul>]{.verbatim} instead. Defines a directory list |
| [<font>]{.verbatim}	    | **Not supported in HTML5.** Use CSS instead. Defines font, color, and size for text |
| [<frame>]{.verbatim}	    | **Not supported in HTML5.** Defines a window (a frame) in a frameset |
| [<frameset>]{.verbatim}	| **Not supported in HTML5.** Defines a set of frames |
| [<noframes>]{.verbatim}	| **Not supported in HTML5.** Defines an alternate content for users that do not support frames |
| [<strike>]{.verbatim}	    | **Not supported in HTML5.** Use [<del>]{.verbatim} or [<s>]{.verbatim} instead. Defines strikethrough text |
| [<tt>]{.verbatim}	        | **Not supported in HTML5.** Use CSS instead. Defines teletype text |
